Cyber Stratagem

A browser-based memory game built as the final project for one of my web development courses.

Cyber Stratagem is a game where players memorize a sequence of arrow keys and repeat it using their keyboard before the timer runs out. As the game progresses, the sequence gets longer and the difficulty increases.

Memorize the arrow sequence shown on screen, use your keyboard arrow keys to repeat it

CSS
JavaScript

This project was focused on practicing JavaScript logic, event handling, and managing game state, along with designing UI
